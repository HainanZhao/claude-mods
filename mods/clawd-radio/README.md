# Clawd Radio

A one-row radio above Claude Code's prompt, with 54 stations played in the
terminal, Singapore's included. Choose all, Singapore only or international
only under **Stations** in `/config`.

```sh
claude plugin marketplace add https://github.com/HainanZhao/claude-mods
claude plugin install clawd-radio@claude-mods
```

Needs `ffplay` and `yt-dlp` (`brew install ffmpeg yt-dlp`). See the
[project README](../../README.md) for how to use it.
